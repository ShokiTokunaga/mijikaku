# 検出ツール

## 実行

Python 3.12以上を使う。使用中のスキルの `scripts/detect.py` に、対象の `.md` ファイルまたはディレクトリと出力先を絶対パスで渡す。ディレクトリは再帰的に検査する。出力先には検査対象の外にある新しいJSONファイルを指定する。

Linux・macOSのsh系シェル

```bash
python3 -B "/スキル配置先/mijikaku/scripts/detect.py" "/対象/設計書.md" --out "/一時作業場所/候補.json"
```

WindowsのPowerShell

```powershell
py -3 -B "C:\スキル配置先\mijikaku\scripts\detect.py" "C:\対象\設計書.md" --out "C:\一時作業場所\候補.json"
```

## 出力

出力はファイルごとに検出理由でまとめ、候補を1行ずつ並べる。ディレクトリ指定時のファイル名は、対象からの相対パスで示す。

ファイル内は、語や同文の繰り返し、否定・前置き・言い回しなどの表現、括弧書き、長さの順に並べる。同じ理由の候補は原文の行順に並ぶ。

```json
{
  "設計書.md": {
    "同文の繰り返し": [
      [62, "入力された明細を表示順に並べて画面に返す。", [17]]
    ],
    "手順の予告": [
      [48, "次の順で"]
    ],
    "長い段落": [
      [80, "一覧の取得条件と表示順を定める。…", 265, 4]
    ]
  }
}
```

各候補は `[行番号, 該当箇所]` で始まる。

行番号はフロントマターを含む原文の先頭を1とし、段落・表セル・箇条書き項目の開始行を示す。HTMLで直接書いたブロック内では、そのブロックの開始行を示す。

該当箇所には、一致した文字列を入れる。複数の文字列が一致した場合は配列になる。長さで検出した場合は本文の冒頭36字までを入れる。

- 括弧内の文章が「。」で終わると、「括弧書き」の理由を付ける。
- 同文の繰り返しには初出の行番号の配列を添える。
- 長さで検出した箇所には文字数、文数を順に添える。「表セル全体が120字超」はセル全体の値を示す。「表セルの同じ行に複数の文」は該当する表示行ごとの値を示す。
- 同じ原文行に複数の候補があり、該当箇所が候補の一部の場合は、候補全体の表示文を末尾に添える。

候補に複数の検出理由があるときは、それぞれの理由に載る。実行時に表示する件数は、段落・表セル・箇条書き項目ごとに数える。

本文の段落・表セル・箇条書き項目を検査する。先頭のYAMLフロントマターは除く。
